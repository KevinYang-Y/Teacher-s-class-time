# 教师课时统计网页

这是一个从零搭建的静态单页版本，直接打开 `index.html` 即可使用。数据保存在当前浏览器的 `localStorage` 中。

## 默认账号

- 管理员：admin / admin123
- 教师：wang / 123456
- 教师：li / 123456

## 已实现

- 教师账号登录
- 管理员查看所有教师的日、月、年和全部课时
- 管理员新增、编辑、删除教师账号
- 管理员按日期修改任意时间段的教师登记
- 管理员可按数量批量设置当天课节，也可单独勾选当天开放哪些课节
- 管理员可点击某位教师，进入该教师当天的单独课时管理
- 教师查看当前月日历
- 教师点击日期查看当天课程时间
- 默认课节为正课8节、晚自习4节
- 同一节课支持多位教师登记，也支持同一教师重复登记多次
- 教师给任意开放时间段登记自己的姓名，并可撤销自己的登记
- 教师查看当天、当月、当年统计
- 教师登录后可以修改自己的密码

## 说明

当前版本适合本机演示或小范围试用。正式部署到学校或机构使用时，建议增加后端服务、数据库、密码加密、权限校验和多人同时编辑保护。
